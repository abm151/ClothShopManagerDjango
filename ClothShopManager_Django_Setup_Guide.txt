ClothShopManager (Python + Django) Setup Guide

Completed

1.  Verified Python: python3 –version

2.  Verified pip: pip3 –version

3.  Installed Django: pip3 install django

4.  Created Django project: cd Documents django-admin startproject
    ClothShopManagerDjango

5.  Enter project: cd ClothShopManagerDjango

6.  Start server: python3 manage.py runserver

7.  Open browser: http://127.0.0.1:8000/
